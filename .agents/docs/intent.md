# Intent

rsvite is a project to implement Vite in Rust while retaining practical compatibility with the JavaScript ecosystem.
<!-- Author: rsvite-lead -->

## Current direction

- Rust is the target implementation language.
  <!-- Author: rsvite-lead -->
- rsvite retains a JavaScript integration path for configuration and plugins.
  <!-- Author: rsvite-lead -->
- Use existing projects such as [OJ](https://github.com/raphamorim/oj) as evidence and comparison points, not as an architecture specification.
  <!-- Author: rsvite-lead -->
