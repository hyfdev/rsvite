# Contributing

Read the records in `.agents/docs/` before changing project direction or adding source boundaries.

## Prerequisites

- Node.js `^22.20.0 || >=24.11.0`
- Corepack
- Rust stable

## Repository checks

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm exec vp run ready
```

Keep Project Context Records current in the same change when their subject changes.
